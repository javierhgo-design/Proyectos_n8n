Aviso de Privacidad

Entorno de pruebas para integración de WhatsApp y automatización mediante n8n.

Entorno exclusivamente técnico.

Esta página forma parte de un entorno de pruebas utilizado para validar la conectividad, recepción y procesamiento de mensajes entre WhatsApp, servicios de integración y n8n.

El entorno no está destinado actualmente a la prestación de servicios comerciales ni a la recopilación sistemática de datos personales.

2. Información que puede ser procesada

Durante las pruebas técnicas, el sistema puede procesar temporalmente información necesaria para validar la integración, incluyendo:

  • Número telefónico asociado a WhatsApp.
  • Nombre o identificador de la cuenta.
  • Contenido de mensajes enviados durante las pruebas.
  • Fecha y hora de las interacciones.
  • Identificadores técnicos de mensajes.
  • Información técnica necesaria para procesar el webhook.

No se solicita ni se recomienda enviar información financiera, contraseñas, documentos de identidad, información médica o datos personales sensibles durante estas pruebas.

3. Finalidad

La información será utilizada exclusivamente para:

  • Validar la conectividad con WhatsApp.
  • Probar la recepción y procesamiento de webhooks.
  • Validar flujos de automatización en n8n.
  • Identificar y solucionar problemas técnicos.
  • Verificar el funcionamiento de las integraciones.

Los datos no serán utilizados para publicidad, venta de información, elaboración de perfiles comerciales ni finalidades distintas a las anteriores.

4. Seguridad de la información

Nivel de seguridad: Alto — Entorno técnico de pruebas

Se aplican medidas técnicas y administrativas razonables para reducir el riesgo de acceso, modificación, pérdida o divulgación no autorizada de la información.

  • Comunicación mediante conexiones cifradas HTTPS/TLS.
  • Acceso restringido a los sistemas de integración.
  • Protección de credenciales y secretos de API.
  • Principio de mínimo privilegio.
  • Minimización de información almacenada.
  • Eliminación de información utilizada para pruebas cuando ya no sea necesaria.
  • Separación entre configuraciones de prueba y producción.

Debido a la naturaleza de Internet y de los servicios de terceros, ningún sistema puede garantizar seguridad absoluta. Las medidas anteriores buscan proporcionar un nivel de protección adecuado para el propósito limitado de este entorno.

5. Servicios tecnológicos

Para realizar la integración pueden intervenir servicios tecnológicos de terceros, incluyendo plataformas de comunicación, APIs, infraestructura de alojamiento y herramientas de automatización como n8n.

Estos servicios podrán procesar información únicamente en la medida necesaria para proporcionar la funcionalidad técnica correspondiente.

6. Conservación

La información utilizada durante las pruebas será conservada únicamente durante el tiempo necesario para validar y diagnosticar la integración.

Cuando sea técnicamente posible, los datos serán eliminados, anonimizados o sustituidos por información ficticia una vez finalizada la prueba.

7. Derechos de los titulares

Las personas titulares de los datos personales podrán solicitar información sobre el tratamiento de sus datos o ejercer los derechos que correspondan conforme a la legislación mexicana aplicable.
